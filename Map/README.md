## 구성 (단위 m, Blender Z-up)

- 잔디 원판 Ø28 → 돌 광장 Ø13 (윗면 z=0) → 중앙 무대 원 Ø4.6 (밝은 돌 + 어두운 링)
- 캐릭터 뒤(+Y): 나무 울타리 반원 r=5.6, 가운데 붉은 문(3.6m) + 기와 지붕, 그 뒤 낮은 돌담 r=8.2
- 소품: 석등 2, 소나무 2(좌), 단풍나무 2(우), 과녁(우), 목검 훈련 인형(좌), 무기 걸이, 돌 물확, 바위 7
- 카메라 `CAM_preview` 40mm, 거리 4.8m, 높이 1.6m → 150프레임 동안 ±30° 궤도 왕복
- 참조 캐릭터 `HERO_REF` 컬렉션 = `Gukgung_3P.glb` (구도 확인용, **내보내지 않음**)

## 오버데어에 넣는 법

1. 일반 Import 로 `stage_preview.fbx` 한 개. 설정은 리그와 동일 (CM). 스켈레톤 없음.
2. `Workspace.rig_japan_full` / `rig_korea_full` 이 서 있는 자리에 놓는다.
   무대 원점 = 캐릭터 발. **무대 정면(카메라 쪽) 이 Blender -Y** 이므로 리그의 LookVector 와 맞춰 돌린다.
   (`SkillPreviewConfig.FacingDegrees = 155` 참고)
3. `SkillPreviewPlayer` 는 카메라를 캐릭터 정면 `FrameSpan/(2·tan(fov/2)·0.52)` ≈ 4m 앞에 둔다.
   울타리·문이 카메라 반대편(뒤)에 오면 맞게 놓인 것이다.

## 색을 텍스처로 옮긴 방식

재질은 전부 프로시저럴 노드(브릭 = 돌 타일, 웨이브 = 나무결·기와·짚, 노이즈 = 잔디·잎·바위·칠 마모)다.
내보낼 때 파츠를 평가된 메시(모디파이어 적용)로 합치고 스마트 UV 를 편 뒤, Cycles 로 **DIFFUSE 컬러만** 2048 아틀라스에 베이크한다.
범프·러프니스는 베이크에 안 들어간다 (오버데어 재질 1개 제약). 리임포트로 28×28×5.3 m, 텍스처 링크, 렌더까지 확인했다.

## 퀄리티 패스에서 바뀐 것 (2026-09-18 오후)

- 돌 광장: 단색 → 판석 타일(브릭 텍스처 + 타일별 톤 편차)
- 울타리: 각 기둥에 베벨 + 사각 갓, 살대는 대나무 마디가 있는 원기둥
- 문: 위로 휘는 갓기둥(가사기), 처마가 들리는 기와 지붕 + 기와 골 34줄 + 용마루 장식, 매단 종이등 2개, 쇠테
- 석등: 창 4면 음각, 받침·지붕 베벨, 목 추가
- 나무: 소나무 = 디스플레이스 원뿔 5단 + 가지, 단풍 = 디스플레이스 구 6개 + 가지 4개
- 바위·덤불: 아이코스피어 subdiv 2 + 노이즈 디스플레이스, 바위는 플랫 셰이딩
- 잔디: 원판을 세분해 노이즈로 완만한 굴곡, 광장은 0.3 m 두께라 뚫고 나오지 않음
- 뒷담: 돌 2단 2열 낱개 + 기와 갓
- 노보리 깃발 2개(좌 붉은 띠, 우 검은 띠)를 무대 좌우에 추가

## 영상 다시 만들기

```
blender -b Map\PreviewStage.blend -P Map
ender_video.py
```

클립 13개(`Wakizashi_Skills\*.fbx` 11 + `Gukgung_3P*_For_OVDR.fbx` 2)를 하나씩 불러와 그 길이만큼 렌더하고
(`CAM_preview` 는 -12° 에서 시작해 초당 6° 로 돌다 +18° 에서 멈춘다 — 짧은 클립은 거의 정지. 상단 `CAM_*` / `SLOW_UNDER_SEC` 로 조절) 끝나면 `assemble_video.py` 를 불러 자막을 얹고 MP4 로 묶는다.
프레임당 0.16 s, 전체 785프레임 약 2.5분. FBX 캐릭터는 그대로 카메라(-Y)를 본다 — 회전 보정 불필요.
Steam 빌드 Blender 는 FFMPEG 출력이 없어서 인코딩은 `imageio-ffmpeg` 로 한다.

## 다시 뽑기

`PreviewStage.blend` 를 열고 `EXPORT` 컬렉션의 `PreviewStage` 를 지운 뒤, 이 세션의 export 스니펫을 다시 돌리면 된다
(합치기 → 스마트 UV → Cycles 베이크 → FBX). 파츠는 `MAP`/`PROPS` 에서 자유롭게 고쳐도 된다.

## 안 한 것

- Higgsfield 생성 에셋: 이 세션에서 Higgsfield Blender 브리지가 응답하지 않아(타임아웃) 전부 로컬 블록아웃으로 대체했다.
  연결되면 문·석등·나무를 `[GEN]` 으로 교체하면 된다 (자리·크기는 위 표 그대로).
- 오버데어 스튜디오 임포트: 스튜디오가 꺼져 있어 못 넣었다. 위 "넣는 법" 대로 수동 임포트.
- 충돌: 메시 그대로. 캐릭터가 걸어다니는 맵이 아니라 필요 없다.
