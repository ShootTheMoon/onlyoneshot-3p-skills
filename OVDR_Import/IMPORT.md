# 임포트 목록 (2026-09-17 최종)

앞서 넣은 것들은 다 무시해도 된다. **이 두 개만 넣으면 된다.**

| 파일 | 내용 | 크기 |
|---|---|---:|
| `rig_japan_full.fbx` | 몸 + 칼2 + 쿠나이 + **클립 11개** | 3.47MB |
| `rig_korea_full.fbx` | 몸 + 활 + 시위 + 화살 + **클립 2개** | 0.89MB |

## 왜 한 파일에 합쳤나

클립을 따로 임포트하면 **파일마다 스켈레톤이 새로 생긴다.** 리그의 스켈레톤과 다른 물건이라
아무리 뼈 이름이 같아도 안 물린다. 그래서 여태 화면에 나온 건 전부 바인드 자세였고,
실제로 애니가 돈 적은 한 번도 없었다 (0.3초·1.5초 화면이 픽셀 단위로 같았다).

한 파일에 리그와 클립을 같이 담으면 전부 같은 스켈레톤을 공유한다.

## 각 파일 구성 (재임포트해서 검증함)

```
rig_japan_full.fbx    메시 1개 Wakizashi3P 26,574tri / 본 22 / 테이크 11 / 텍스처 포함
rig_korea_full.fbx    메시 1개 Gukgung3P    4,722tri / 본 22 / 테이크  2 / 텍스처 포함
```

클립 11개 = Idle, Attack1·2·3, BlockIn·Hold·Out, KunaiThrow, Teleport, Draw, Ryunochi
클립 2개 = DrawRelease(세로 사격), HorizontalAttack(가로 사격)

## 넣는 법

일반 Import 로 한 개씩. 설정은 지금까지와 동일 (Custom Skeleton / Use skeleton from FBX / CM).

넣고 나면 알려달라. 에셋 테이블에서 새 애니 id 를 읽어 `SkillPreviewConfig.lua` 를 다시 맞추고,
리그를 `ReplicatedStorage` 로 옮긴 뒤 재생까지 확인한다.

## 고친 것

- **무기가 손에서 뭉개지던 문제** — 무기 위치를 포즈 상태에서 계산하고 나중에 포즈를 지워서
  어긋나 있었다. 레스트로 되돌린 뒤 묶도록 순서를 바꿨다. 렌더로 칼 두 자루 정상 확인.
- **파츠가 벌어지던 문제** — 액션만 떼고 포즈 본을 안 지워서 바인드가 '칼 쥔 자세'로 굳어 있었다.
- **색** — 재질 색을 텍스처 한 장으로 베이크해 FBX 안에 넣었다.
- **첫 클릭 지연** — 로비 입장 시 클립을 미리 한 번 로드해두는 코드를 넣었다 (반영 완료).
